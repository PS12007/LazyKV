# LazyKV

Tiered KV-cache runtime for long-context LLM inference on a single 8 GB consumer GPU.
Research question: under a fixed GPU KV budget, how much context and quality can be
retained by intelligent block residency, migration, compression and prefetching?

Full brief: `docs/BRIEF.md`. Read it at the start of every phase.

## Hard rules

1. NO FABRICATED NUMBERS. Every number in any .md file must be generated by a script
   reading from `results/**/metrics.json`. Never hand-type a benchmark value into a
   document. If an experiment has not run, write `not measured`.
2. NO FABRICATED CITATIONS. Every paper cited must be verified by an actual web search
   and recorded with its arXiv ID or venue in `docs/RELATED_WORK.md`. If you cannot
   find it, say so and remove it.
3. PHASE GATES. At the end of each phase: run tests, run one real experiment, write
   `docs/phases/PHASE_N.md`, commit, then STOP and report. Do not roll into the next
   phase without being told.
4. NEVER RUN A LONG BENCHMARK IN THE FOREGROUND. Anything over ~90s gets launched
   detached with output to a log file, then polled. You will time out otherwise.
5. NO NEW DEPENDENCIES without asking. The env is fragile (Blackwell GPU). Use `uv`
   and keep `requirements.lock` current.
6. SMALL COMMITS with conventional-commit messages. One logical change per commit.
7. WHEN A RESULT IS BAD, REPORT IT. Negative results are the deliverable. Do not tune
   an experiment until it looks good and then present it as the finding.
8. ASK BEFORE CHANGING THE RESEARCH DIRECTION. If a measurement invalidates the
   premise of a phase, stop and say so rather than silently redesigning around it.

## Environment

- Windows 11, RTX 5060 Laptop (Blackwell, sm_120), 8 GB VRAM, single GPU, no cloud.
- PyTorch must be a cu128+ build. Default pip wheels may lack sm_120 kernels.
- Verify with: `torch.cuda.get_device_capability()` should be `(12, 0)` and a real
  matmul must execute without a no-kernel-image error.
- The project env is `.venv/` (standalone, created with `UV_LINK_MODE=copy`). Run
  everything with `.venv\Scripts\python.exe`. Never install into, or run pip against,
  any sibling project's environment (e.g. `..\tritonkv\.venv`).

## Docs pipeline (how rule 1 is enforced)

Prose lives in `docs/templates/*.md.tmpl`. Numbers are placeholders resolved from
`results/**/metrics.json` by `scripts/render_docs.py`. Missing values render as
`not measured`. `tests/test_docs_fresh.py` fails if a rendered doc is stale.

## Style

Python 3.11+, type hints, dataclasses, structured logging, config-driven (YAML),
small modules. Comments explain WHY a systems decision was made. No web frontend.
No global mutable state. No abstraction that does not yet have two users.
